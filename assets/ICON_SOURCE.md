# Icon source

Icons are downloaded from the selfh.st icon collection (repository `selfhst/icons`,
served via jsdelivr), which provides ready-made logos for self-hosted applications.
No icon was drawn or modified by hand.

| File in this repo | Upstream file | Used for |
|---|---|---|
| `icon.svg` | `svg/open-webui.svg` | Default (fallback in the README `<picture>` block) |
| `icon-light.svg` | `svg/open-webui-dark.svg` | Dark-colored logo for light backgrounds |
| `icon-dark.svg` | `svg/open-webui-light.svg` | Light-colored logo for dark backgrounds |

Download URLs:

- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/open-webui.svg
- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/open-webui-dark.svg
- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/open-webui-light.svg
